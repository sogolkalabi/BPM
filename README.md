# Business Process Management and Process Mining

This repository contains selected academic projects I completed during my Industrial Engineering studies. The projects gave me practical experience with business process modelling, process discovery, model evaluation, and event-log analysis.

## Projects

### 1. BPI Challenge 2012 – Event Log Analysis
Analysis of a banking event log using Python, including process behaviour, case outcomes, throughput times, and rework.

### 2. Process Discovery
Python-based work on process discovery from event data and the analysis of process relationships.

### 3. Process Model Evaluation
Analysis of process models and their behaviour in relation to observed event-log traces.

### 4. BPMN Modelling
BPMN models created with Camunda Modeler for selected business processes.

## Tools and Methods

- Python
- Event-log analysis
- Process discovery and model evaluation
- BPMN 2.0 and Camunda Modeler

These projects reflect my academic interest in understanding business processes through data and exploring how process analysis can support operational improvement.
